# Tutoring Platform API — Documentation

Backend API for the tutoring platform. Built with **FastAPI + SQLAlchemy (async) + PostgreSQL**.

- **Base URL:** all routes are mounted under `/api/v1` (except `/health`).
- **Interactive docs:** `GET /docs` (Swagger UI) and `GET /redoc` are auto-generated by FastAPI from the code. These hand-written docs complement Swagger by describing the auth model and business logic that the code alone doesn't convey.
- **Content type:** request and response bodies are JSON unless noted.
- **IDs:** all resource identifiers are UUIDs (v4).
- **Timestamps:** ISO-8601 with timezone (e.g. `2026-09-02T10:00:00+00:00`).

## Authentication & Authorization

### How auth works

Authentication is **Google OAuth → JWT**. After completing the OAuth handoff (see [auth.md](auth.md)), the client receives a JWT. Send it on every protected request:

```
Authorization: Bearer <access_token>
```

The token is decoded on each request to resolve the current `User`. Invalid/expired tokens return `401`. A missing token on a protected route returns `401 Not authenticated`.

### Roles

There are three roles (`UserRole`): `admin`, `professor`, `student`.

The dependencies that guard routes:

| Dependency | Who passes |
|---|---|
| `get_current_user` | any authenticated user |
| `student_only` | any authenticated user (admin, professor **and** student — the alias `require_student` allows all three roles) |
| `professor_only` | `professor` or `admin` |
| `admin_only` | `admin` only |
| `enrolled_for_course` / `_chapter` / `_lecture` / `_exercise` | admin (always), professor (if assigned to the course), student (if enrolled in the course) |

> **Note on `student_only`:** despite the name, this dependency permits admins and professors as well — it simply requires a valid authenticated user of any role. It is used on the "catalogue"/list endpoints.

### Common error responses

| Status | Meaning |
|---|---|
| `401 Unauthorized` | missing, invalid, or expired token; user no longer exists |
| `403 Forbidden` | authenticated but role/enrollment check failed |
| `404 Not Found` | resource does not exist |
| `409 Conflict` | uniqueness/capacity/overlap conflict |
| `422 Unprocessable Entity` | request body/query failed validation |

Error bodies follow FastAPI's shape: `{"detail": "..."}`.
